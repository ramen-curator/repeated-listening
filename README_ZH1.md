# Activity 6.1: 重复听流畅度训练器 (Repeated Listening Fluency Trainer)

[English](README.md) | **简体中文** | [日本語](README_JA.md)

一款零依赖、单文件运行的浏览器端外语听力解码与反应速度训练工具。本项目基于语言学家 Paul Nation 在《学语言你需要知道什么》（*What Do You Need to Know to Learn a Foreign Language?*）中提出的 **“活动 6.1：重复听 (Activity 6.1: Repeated listening)”**，通过高频随机播报与递进式语速调节，帮助学习者跳过母语心译，建立目标语词汇、数字及常用表达的直接听觉反射。

## 核心特性

- **多语言界面切换（中 / 英 / 日）**：支持通过页面右上角按钮在 **中文**、**English**、**日本語** 之间一键切换；未手动修改的内置预设数据集标题与释义会随界面语言自动本地化。
- **双训练模式**：
  - **指认模式 (Pointing Mode)**：还原 Paul Nation 原书的经典指认练习——听随机语音播报，在下一词读出前用手指或视线快速定位看板上的对应卡片。
  - **测验模式 (Quiz Mode)**：在播报间隔内点击看板上的对应卡片，系统实时判定正误并统计正确率与得分。
- **精细化速度与节奏控制**：
  - **播报语速 (Speech Rate)**：支持 `0.6x` 至 `1.6x` 无级调节（步长 `0.05x`，默认 `1.0x`）。
  - **停顿间隔 (Pause Interval)**：支持 `0.2s` 至 `5.0s` 反应时间调节（步长 `0.1s`，默认 `1.8s`）。
  - **重复次数 (Repetition Count)**：可设置单轮训练中每个词条随机出现的次数（`1`–`20` 次，默认 `4` 次），自动生成打乱且均衡的听力序列。
- **内置预设与自定义数据集**：
  - 开箱内置 5 组预设数据：**英语基础数字 (1–10)**、**英语星期**、**英语月份**、**日语基础数字 (1–10)**、**西班牙语常见食物**。
  - 支持新建、编辑、保存与删除自定义数据集，采用直观的 `朗读文本 | 卡片显示内容` 单行格式。
- **看板辅助与快捷键控制**：
  - 支持随时开启/隐藏卡片上的发音字幕（**显示字幕**）以调节难度，或开启 **随机打乱看板** 防止依靠位置记忆。
  - 提供完整的播报控制：**开始**、**暂停/继续**（支持 `Space` 空格键快捷操作）、**重播当前词** 与 **停止**。
- **纯本地运行与数据持久化**：调用浏览器原生 Web Speech API (`window.speechSynthesis`) 进行语音合成，所有自定义数据集与界面语言偏好均自动保存在浏览器 `localStorage` 中，无需联网后端或 API Key。

## 理论依据

本工具对应 Paul Nation 语言学习“四主线 (Four Strands)”框架中“流利度发展 (Fluency Development)”主线下的 **活动 6.1：重复听**（参见《学语言你需要知道什么》，[外研社图书介绍页](https://www.fltrp.com/c/2019-09-02/516248.shtml)）：

> **活动 6.1：重复听 (Activity 6.1: Repeated listening)**
>
> 找人以外语随机读出一到十的数字并录音，例如：6, 3, 8, 1, 7, 10, 2, 9, 4, 5, 3, 10, 3, 6。每个数字都应该在不同的地方出现几次，这样你就有充分的机会一遍又一遍地听到同一个数字，而不知道它什么时候会出现。在一张纸上按顺序写下 1 到 10，当你听录音时，用手指着你听到的数字。当你能快速轻松做到时，提高速度再做一次。坚持这样做，直到你能轻松听出这些数字的读音。最好将练习分散在几天内进行，而不是集中在一次做完。
>
> 这项活动利用了重复和提高速度，能快速培养理解数字的流利度。你也可以用它来练习星期、月份、问候语、食物名称以及许多其他内容。

## 快速开始

1. 克隆或下载 [ramen-curator/repeated-listening](https://github.com/ramen-curator/repeated-listening) 仓库到本地：
   ```bash
   git clone https://github.com/ramen-curator/repeated-listening.git
   ```
2. 直接使用任意现代浏览器（Chrome、Edge、Safari 或 Firefox）打开 [`index.html`](https://github.com/ramen-curator/repeated-listening/blob/main/index.html) 即可运行。
3. 点击右上角语言栏（**中文** / **English** / **日本語**）可随时切换界面与默认预设语言。

## 使用指南

| 步骤 | 操作项 | 详细说明 |
| :--- | :--- | :--- |
| **1. 配置数据集** | 选择预设或新建词库 | 从下拉菜单选择 5 组内置预设之一，或点击 **新建** 按每行一条 `朗读文本 \| 卡片显示` 的格式输入自定义内容并点击 **保存**。 |
| **2. 选择发音引擎** | 匹配目标语言语音 | 在 **语音选择 (TTS)** 中选择与当前练习语种一致的系统/浏览器发音人（如 `en-US`、`ja-JP`、`es-ES`）。 |
| **3. 设定参数与模式** | 调节语速、间隔与交互方式 | 初次练习建议保持默认语速（`1.0x`）与停顿间隔（`1.8s`），可按需选择 **指认模式** 或 **测验模式**。 |
| **4. 循序提速训练** | 反复练习并逐步提速 | 点击 **开始训练**（可按 `Space` 键暂停/继续）。当在当前速度下能轻松反应后，逐步调高 **播报语速** 或缩短 **停顿间隔**。 |

### 自定义数据格式

在数据集编辑框中，每行填写一条数据，使用竖线（`|`）分隔发音文本与卡片标签：

```text
朗读文本 | 卡片显示内容
```

- **`朗读文本`**：由浏览器 TTS 引擎实际朗读的外语单词、短语或假名（开启字幕时也会显示在卡片下方）。
- **`卡片显示内容`**：看板卡片中央突出展示的数字、母语释义或提示符号。
- 若某行不包含 `|`，则朗读文本与卡片显示内容默认使用同一字符串。

**示例（日语星期练习）：**

```text
げつようび | 周一 (月)
かようび | 周二 (火)
すいようび | 周三 (水)
もくようび | 周四 (木)
きんようび | 周五 (金)
どようび | 周六 (土)
にちようび | 周日 (日)
```
