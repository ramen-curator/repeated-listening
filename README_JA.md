# Activity 6.1: 反復リスニング流暢性トレーナー (Repeated Listening Fluency Trainer)

[English](README.md) | [简体中文](README_ZH.md) | **日本語**

外部ライブラリ不要・単一HTMLファイルで動作する、外国語リスニングの解読速度と反応スピードを鍛えるブラウザツールです。言語学者 Paul Nation の著書『*What Do You Need to Know to Learn a Foreign Language?*』で紹介されている **「Activity 6.1: Repeated listening（反復リスニング）」** に基づき、ランダム順の音声読み上げと段階的な速度調整によって、頭の中で母語に翻訳することなく数字や頻出語彙を瞬時に聴き取る流暢性（Fluency）を養います。

## 主な機能

- **多言語インターフェース対応（日 / 英 / 中）**：画面右上のボタンから **日本語**・**English**・**中文** をワンクリックで切り替え可能。未編集のプリセットデータセット名とカード表記も、選択したUI言語に合わせて自動的にローカライズされます。
- **2つのトレーニングモード**：
  - **ポインティングモード (Pointing Mode)**：Paul Nation の原典通りに、ランダムに読み上げられる音声を聴きながら、次の単語が再生される前にボード上の対応するカードを指や視線で素早く指し示すモードです。
  - **クイズモード (Quiz Mode)**：ポーズ間隔のあいだに該当するカードをクリックし、正誤判定とスコアをリアルタイムに記録するインタラクティブモードです。
- **きめ細かい速度・ペース設定**：
  - **読み上げ速度 (Speech Rate)**：`0.6x` から `1.6x` まで調整可能（`0.05x` 刻み、デフォルト `1.0x`）。
  - **ポーズ間隔 (Pause Interval)**：音声間の反応時間を `0.2s` から `5.0s` まで調整可能（`0.1s` 刻み、デフォルト `1.8s`）。
  - **反復回数 (Repetition Count)**：1セッションあたり各アイテムが出現する回数を設定（`1`〜`20`回、デフォルト `4`回）し、ランダムな出題シーケンスを自動生成します。
- **内蔵プリセットとカスタムデータセット管理**：
  - すぐに使える5種類のプリセットを内蔵：**英語：基本の数字 (1–10)**、**英語：曜日**、**英語：月**、**日本語：基本の数字 (1–10)**、**スペイン語：よくある食べ物**。
  - `読み上げテキスト | カード表示ラベル` のシンプルな1行フォーマットで、独自のデータセットを新規作成・編集・保存・削除できます。
- **ボード補助機能とショートカット**：
  - カード上の読み上げテキスト表示の切り替え（**字幕を表示**）や、位置暗記を防ぐ **カードのシャッフル** に対応。
  - **開始**、**一時停止 / 再開**（`Space` キー対応）、**現在の単語を再生**、**停止** の各種再生コントロールを搭載。
- **完全ローカル動作＆自動保存**：ブラウザ標準の Web Speech API (`window.speechSynthesis`) と `localStorage` を使用。サーバー通信やAPIキーは一切不要で、作成したデータセットや言語設定はブラウザ内に自動保存されます。

## 理論的背景

本ツールは、Paul Nation が提唱する言語学習の「4つのストランド (Four Strands)」のうち、「流暢性の向上 (Fluency Development)」に含まれる **Activity 6.1: Repeated listening** を実装したものです（参考：[『What Do You Need to Know to Learn a Foreign Language?』](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/paul-nations-publications/publications/documents/foreign-language_1125.pdf)）：

> **Activity 6.1: Repeated listening（反復リスニング）**
>
> 学習している外国語で1から10までの数字をランダムな順序（例：6, 3, 8, 1, 7, 10, 2, 9, 4, 5, 3, 10, 3, 6）で誰かに録音してもらいます。いつ出てくるか予測できない状態で同じ数字を何度も聴く機会が得られるよう、それぞれの数字が異なる場所で複数回出現するようにします。紙に1から10までの数字を順番に書き出し、録音を聴きながら聞こえた数字を指で差していきます。素早く簡単にできるようになったら、速度を上げて繰り返します。数字の音声を楽に聴き取れるようになるまでこれを続けます。一度にまとめて行うのではなく、数日間に分けて練習するのが最も効果的です。
>
> この活動は「反復」と「速度の上昇」を活用して、数字を理解する流暢性を短期間で高めます。曜日、月、挨拶、食べ物の名前など、他の多くの語彙の練習にも応用できます。

## セットアップ方法

1. [ramen-curator/repeated-listening](https://github.com/ramen-curator/repeated-listening) リポジトリをクローンまたはダウンロードします：
   ```bash
   git clone https://github.com/ramen-curator/repeated-listening.git
   ```
2. モダンブラウザ（Chrome、Edge、Safari、Firefox など）で [`index.html`](https://github.com/ramen-curator/repeated-listening/blob/main/index.html) を直接開くだけで起動します。
3. 画面右上の言語切り替えボタン（**中文** / **English** / **日本語**）から表示言語を選択できます。

## 使い方

| ステップ | 操作項目 | 詳細 |
| :--- | :--- | :--- |
| **1. データセット設定** | プリセット選択または新規作成 | 5つの内蔵プリセットから選択するか、**新規作成** をクリックして1行につき1ペアの `読み上げテキスト \| カード表示` を入力し、**保存** を押します。 |
| **2. 音声エンジンの選択** | 学習言語のTTS音声を選択 | **音声選択 (TTS)** メニューから、練習する言語に合ったシステム/ブラウザ音声（`en-US`、`ja-JP`、`es-ES` など）を選択します。 |
| **3. ペースとモードの設定** | 速度・間隔・モードの調整 | 最初は無理のない **読み上げ速度**（`1.0x`）と **ポーズ間隔**（`1.8s`）から始め、目的に応じて **ポインティングモード** または **クイズモード** を選びます。 |
| **4. 反復とスピードアップ** | セッション実行と段階的な加速 | **スタート** を押して練習を開始します（`Space` キーで一時停止/再開）。余裕を持って反応できるようになったら、少しずつ速度を上げるかポーズ間隔を短縮します。 |

### カスタムデータセットの書式

データセット編集欄に、パイプ記号（`|`）で区切って1行に1アイテムずつ記述します：

```text
読み上げテキスト | カード表示ラベル
```

- **`読み上げテキスト`**：Web Speech API のTTSエンジンが実際に読み上げる外国語の単語やフレーズ（字幕表示オン時にはカード下部にも表示されます）。
- **`カード表示ラベル`**：ボード上のカード中央に大きく表示される数字、意味、または記号。
- 行内に `|` がない場合は、読み上げテキストとカード表示ラベルの両方に同じ文字列が使用されます。

**入力例（フランス語の数字 1–5）：**

```text
un | 1
deux | 2
trois | 3
quatre | 4
cinq | 5
```
